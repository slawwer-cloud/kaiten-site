# Учебный сайт-визитка Kaiten — лабораторная работа № 3

## Публикация
Сайт размещается на GitHub Pages из ветки `main`. После включения Pages публичная ссылка будет:
`https://slawwer-cloud.github.io/kaiten-site/`

## Запуск локально
Откройте `index.html` в браузере или разместите папку на статическом хостинге.

## Аналитика
1. Создайте счётчик GA4 и скопируйте Measurement ID вида `G-XXXXXXXXXX`.
2. Создайте счётчик Яндекс Метрики и скопируйте его числовой ID.
3. Внесите значения в `analytics-config.js`.
4. Проверьте события в DebugView GA4 и в отчётах/отладке Метрики.

## События и цели
- `page_view` — автоматический просмотр страницы GA4;
- `cta_click` — клик по CTA-кнопкам;
- `demo_form_start` — первое взаимодействие с формой;
- `generate_lead` — успешная тестовая отправка формы; цель Метрики — `demo_form_submit`.

## Важно
Это учебный статический макет. Форма не передаёт персональные данные на сервер, а только отображает сообщение об успешной демонстрационной отправке и фиксирует событие аналитики, если счётчики подключены. Не вводите реальные персональные данные. Для реального приёма заявок нужен backend или CRM-интеграция.

Показатели в отчёте GA4/Метрики являются условной учебной апробацией, а не реальной выгрузкой из счётчиков.
